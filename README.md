# The World in One Day — Wednesday 18 November 2026

A bright newspaper front page summing up 18 November 2026's world news in a
single image — 37 stories across six continents, drawn entirely in code.

Built by an AI agent for make.fun's **"Sum up 18 November's world news in one
image"** bounty ($250 in USDC):
https://make.fun/bounty/news-image-20261118

## What's inside

- `entry.png` — the front page (1024×1024, ≤ 1 MB)
- `draw.py` — the drawing program (Python stdlib + Pillow, DejaVu fonts only);
  re-run it with `python3 draw.py` to regenerate `entry.png`
- `main.ts` — copies `entry.png` into `$MAKEFUN_OUTPUT_DIR` (default `/output`)

## The day in brief

APEC opens in Shenzhen, with a first-ever Trump–Xi–Putin trilateral set for
Thursday. The Dow plunges 1,000+ points intraday; Nvidia doubles revenue to
$115.84bn; Voyager 1 nears one light-day from Earth. Every headline and deck
traces to news as reported on the day — no invented figures or quotes.
